# Logos del proyecto Dominica

Coloca aquí los siguientes archivos PNG con fondo transparente:

| Archivo | Descripción | Uso |
|---|---|---|
| `dominica-logo.png` | Logo Dominica Apartamentos verde sobre fondo transparente | Nav principal + portada |
| `dominica-logo-blanco.png` | Logo Dominica en blanco sobre fondo transparente | Footer (sobre negro) |
| `cg-logo.png` | Logo CG Constructora sobre fondo transparente | TopBar superior (sutil) + footer aliados |
| `triple-a-logo.png` | Logo Triple A sobre fondo transparente | TopBar superior (sutil) + footer aliados |

## Cómo exportarlos desde Adobe Illustrator
1. Abrir el archivo .ai
2. File → Export → Export As
3. Formato: PNG
4. Marcar "Transparent" en background
5. Resolution: 300 dpi (alta calidad)
6. Guardar con el nombre exacto de la tabla

## Mientras no existan
Los componentes muestran texto fallback elegante para que la app no se rompa.
